# Psychology Lab

GitHub is the source of truth for the Psychology Lab.

- `public/` — static frontend deployed to GitHub Pages
- `supabase/functions/` — profile sync backend
- `supabase/migrations/` — database schema and RPC migrations
- Supabase project: `statistics-r-lab` (`ibkirlsqpzmhuwssdcjj`)

The Psychology profile data was migrated from Hatchable to Supabase without resetting usernames, notes, progress, flashcards, matching state, quiz state, revisions, or timestamps.

Frontend: https://weather-mister.github.io/psychology-lab/
